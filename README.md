# C Calculator

A simple command-line calculator made in C.

## Features

* Addition
* Subtraction
* Multiplication
* Division
* Takes two numbers as input
* Lets the user choose an operation
* Checks that the selected operation is between 1 and 4

## What I Practiced

While making this project, I practiced:

* `scanf()` and `printf()`
* Variables and data types
* `switch-case`
* `do-while` loop
* Conditional logic
* Floating-point arithmetic

## How to Run

Compile the program using a C compiler:

```bash
gcc Calculator.c -o Calculator
```

Then run it:

```bash
./Calculator
```

## Example

The program asks for two numbers and then lets you choose:

1. Addition
2. Subtraction
3. Multiplication
4. Division
